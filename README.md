## 🚀 How to Host on GitHub Pages (Free Live URL)

1. Create a new repository on your GitHub account (e.g., `kundan-portfolio`).
2. Run these commands inside your portfolio folder:
   ```bash
   git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/kundan-portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** -> **Pages**.
   - Under **Build and deployment** -> **Branch**, select `main` and `/ (root)`.
   - Click **Save**.
4. In ~1 minute, your portfolio will be live at:
   ```text
   https://<YOUR-GITHUB-USERNAME>.github.io/kundan-portfolio/
   ```
